# Salesforce Project Management App

## Overview
This is a Salesforce-based Project Management App created using both Salesforce Admin and Development concepts.  

The main purpose of this project is to manage projects, tasks, teams, and related records in an organized and secure way.

## Features
- Custom Objects and Fields
- Object Relationships
- Validation Rules
- Record Types and Page Layouts
- Flow Automation
- Apex Trigger
- Reports and Dashboards
- Security and User Access Management

## Tools & Technologies
- Salesforce CRM
- Apex
- Flow Builder
- App Manager
- Reports & Dashboards

## Project Highlights
- Used App Manager to bind all objects together into a single application.
- Implemented security concepts to control user access.
- Automated business processes using Flow and Apex Trigger.

## Learning Outcome
This project helped me gain practical knowledge of Salesforce Administration and Development and improved my understanding of real-time business processes.
